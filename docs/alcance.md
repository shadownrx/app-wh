# Alcance del MVP

Producto: app de citas 18+. Métrica principal: **Match-to-Date Rate**.

## Incluido en backend

Registro/login +18, perfil, fotos, descubrimiento con límite diario, match, chat, proponer cita, QR de un solo uso, confirmación mutua, moneda, tienda (mínimo 3 recompensas; hay 8), persona del día, bloquear/reportar, admin y funnel.

## Fase 2 (fuera de este MVP)

Pagos reales, Premium mensual, IA, videollamadas, recompensas físicas, foto conjunta obligatoria, marketplace.

## Hitos

1. Arquitectura, backend, autenticación
2. Perfiles, discovery, matches
3. Chat, notificaciones, citas, QR, moneda
4. Testing, admin, deploy
